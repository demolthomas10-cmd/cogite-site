# CoGîte — site vitrine

Site statique en un seul fichier HTML autonome (`index.html`) : CSS inline, JS minimal, photos encodées en base64, formulaire Formspree (https://formspree.io/f/mqpzvqwp).

- Palette : crème #F5F2EB / vert foncé #12211F / doré #C69B3E
- Titres : Archivo 700/800 (Google Fonts, seule dépendance externe)
- Mobile-first, testé 375px

## Déploiement
Ouvrir `index.html` en local ou déposer le fichier sur n'importe quel hébergement statique (GitHub Pages, Netlify, OVH…).
